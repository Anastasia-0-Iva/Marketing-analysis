# Проект — Marketing-analysis

Этот проект предназначен для анализа демографических данных водителей таксопарка и пользователей, с целью предоставления ценной информации для маркетинговых кампаний. Проект обрабатывает CSV-файлы, вычисляет средний возраст и соотношение полов водителей, а также проводит самостоятельный анализ пола пользователей на основе окончания их имен.

## 🎯 Цель проекта

Предоставить маркетологам подробную демографическую картину как водительского состава, так и клиентской базы, чтобы помочь им в:
- **Таргетировании рекламных кампаний:** Понимание целевой аудитории (водителей и пользователей) для более эффективного распределения рекламного бюджета.
- **Оптимизации маркетинговых стратегий:** Адаптация сообщений и каналов продвижения под конкретные демографические группы.
- **Выявлении закономерностей:** Поиск взаимосвязей между демографическими характеристиками и поведением пользователей/водителей.

## 🚀 Основные возможности

*   **Анализ водителей:**
    *   Загрузка и обработка данных водителей из CSV-файла за последние 5 лет.
    *   Расчет среднего возраста водителей.
    *   Определение процентного соотношения водителей по полу.
*   **Анализ пользователей:**
    *   Самостоятельная разработка фильтра для определения пола пользователя на основе окончания его имени.
    *   Вычисление соотношения полов среди пользователей.

## 🛠️ Технические детали и зависимости

*   **Язык:** Python
*   **Основные библиотеки:**
    *   `pandas` (для обработки и анализа данных)
    *   `typing` (для аннотаций типов)
    *   `datetime` (для работы с датами)

## 🚀 Начало работы

### 1. Получение данных

Убедитесь, что у вас есть CSV-файл с данными о водителях таксопарка. Ожидаемый формат файла должен содержать как минимум:
*   Информацию о возрасте водителей.
*   Имена пользователей для анализа пола.
*   Даты (для фильтрации последних 5 лет).
